# PhishGuard changelog

## v0.1.0 — working MVP

- URL analyzer with lexical, DNS, TLS, RDAP, and opt-in intel signals.
- Email `.eml` analyzer with headers, authentication, links, HTML forms, and attachments.
- QR decoder with destination analysis.
- Static file/attachment analyzer with macro, PDF, archive, and script checks.
- Social-media scam-language analyzer with link analysis.
- Transparent 0–100 scoring, verdicts, confidence, and recommendations.
- JSON and Markdown reports.
- Streamlit UI with five tabs, upload limits, session rate limit, and privacy notes.
- SSRF-safe DNS/TLS checks and in-memory processing.
- Pytest suite and GitHub Actions CI.

## Unreleased

- PDF report export.
- Outlook `.msg` support.
- OCR for social-media screenshots.
- Custom domain.
- ML URL classifier evaluation.
